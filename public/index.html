IP pública / Pinggy.io

      
El panel puede iniciar un túnel TCP automático al puerto del server. En Minecraft usá la dirección sin tcp://.

      

      

      
Comando manual:
ssh -p 443 -R0:localhost:25565 tcp@a.pinggy.io

⏱️ Inactividad
No agregué un bot anti-idle. Lo correcto es subir el timeout oficial de Codespaces a 240 minutos.
GitHub → Settings → Codespaces → Default idle timeout → 240 minutes
